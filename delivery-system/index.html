Version 0.3

Proof-driven delivery system

Everything a Claude Code session needs to take a Jira epic or story and deliver it with proof, alongside several hundred other sessions, using only git and read-only Jira.

The loop: claim the ticket → check it is not already done → challenge the ask → contract → failing proofs, frozen → local spotlight → test track → UAT → prod → regression.
